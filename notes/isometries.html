Isometries in Various Spaces

Seminar Project · Under Prof. S. Ponnusamy, IIT Madras

These notes are results of a discussion/seminar project under the supervision of Prof. S. Ponnusamy, based on the book The Theory of Higher-Dimensional Quasiconformal Mappings by F. W. Gehring, G. J. Martin, and B. P. Palka. This section covers various examples of isometries.

Definitions

Definition 0.1 (Isometry) Let $(X, d_X)$ and $(Y, d_Y)$ be metric spaces. A map $f : X \to Y$ is an isometric embedding (or distance-preserving map) if $$ d_Y\big(f(a), f(b)\big) = d_X(a,b) \quad \text{for all } a, b \in X. $$ If in addition $f$ is surjective, $f$ is called an isometry, and $X$ and $Y$ are said to be isometric.
Definition 0.2 (Isometry of normed spaces) Let $(X, \|\cdot\|_X)$ and $(Y, \|\cdot\|_Y)$ be normed linear spaces over $\mathbb{K} = \mathbb{R}$ or $\mathbb{C}$, each metrised by $d(x,y) = \|x-y\|$. A map $f : X \to Y$ is an isometry (or isometric embedding) if $$ \|f(x) - f(y)\|_Y = \|x - y\|_X \quad \text{for all } x, y \in X. $$ If $f$ is in addition surjective, $X$ and $Y$ are isometric.
Definition 0.3 (Linear isometry) A linear map $T : X \to Y$ is a linear isometry if $$ \|Tx\|_Y = \|x\|_X \quad \text{for all } x \in X. $$ A surjective linear isometry is an isometric isomorphism, written $X \cong Y$ isometrically.
Remark 0.4 (Immediate consequences)
  1. Injectivity is automatic: if $f(a) = f(b)$ then $d_X(a,b) = d_Y(f(a), f(b)) = 0$, so $a = b$.
  2. Continuity is automatic — indeed uniform continuity with $\delta = \varepsilon$. An isometric embedding is a homeomorphism onto its image.
  3. If $f$ is a bijective isometry then $f^{-1}$ is an isometry too.
Proof (of point 3). Define $f^{-1} : Y \to X$. Given $y, y' \in Y$, since $f$ is surjective there exist $x, x' \in X$ with $f(x) = y$, $f(x') = y'$, and these are unique since $f$ is injective; that is, $x = f^{-1}(y)$, $x' = f^{-1}(y')$. Since $f$ is an isometry, $$ d_Y(y, y') = d_Y\big(f(x), f(x')\big) = d_X(x, x') = d_X\big(f^{-1}(y), f^{-1}(y')\big). $$ As $y, y' \in Y$ were arbitrary, $f^{-1}$ preserves distances, i.e. $f^{-1}$ is an isometry. ∎

Examples of Isometries

1. The line

Let $f : \mathbb{R} \to \mathbb{R}$ be given by $f(x) = \alpha x + c$ with $\alpha = \pm 1$, $c \in \mathbb{R}$.

2. Translations

Let $f_v : \mathbb{R}^n \to \mathbb{R}^n$ for $v \in \mathbb{R}^n$, defined by $f_v(x) = x + v$ on $\mathbb{R}^n$.

3. Same set, different metric

Let $X = (0, \infty)$ and define $d(x,y) = |\log x - \log y|$ for $x, y \in X$.

$d$ is a metric. Non-negativity and symmetry are immediate. Moreover $d(x,y) = 0 \iff \log x = \log y \iff x = y$ by injectivity of $\log$, and the triangle inequality is inherited from $\mathbb{R}$, since $d$ is the absolute-value metric pulled back along $\log$: $$ d(x,z) = |\log x - \log z| \le |\log x - \log y| + |\log y - \log z| = d(x,y) + d(y,z). $$

The isometry. The map $\log : \big((0,\infty), d\big) \to \big(\mathbb{R}, |\cdot|\big)$ satisfies $d(x,y) = |\log x - \log y|$ for all $x,y \in X$ by the definition of $d$, and it is a bijection. Hence $\log$ is a surjective isometry, so $\big((0,\infty), d\big)$ and $\mathbb{R}$ are indistinguishable as metric spaces.

4. Rigid motions of $\mathbb{R}^n$

Let $f : \mathbb{R}^n \to \mathbb{R}^n$ be given by $f(x) = Ax + b$ with $A \in O(n)$ and $b \in \mathbb{R}^n$. Every distance-preserving self-map of $\mathbb{R}^n$ is of this form.

5. The shift on $\ell^p$

Let $S : \ell^p \to \ell^p$ with $S(x_1, x_2, \dots) = (0, x_1, x_2, \dots)$. This satisfies $\|Sx\|_p = \|x\|_p$. This is an example of a map which is an isometry but not surjective.

6. Discrete metric

If $d(x,y) = 1$ for all $x \ne y$, every bijection is an isometry. Distance-preservation constrains a map only as much as the metric is rich.

7. Holomorphic isometries of $\mathbb{C}$

Let $f : \mathbb{C} \to \mathbb{C}$ with $f(z) = az + b$ and $|a| = 1$; this is an isometry.

8. Stereographic projection and the chordal metric

Let $S^n = \{x \in \mathbb{R}^{n+1} : |x| = 1\}$ with north pole $e_{n+1}$, and let $$ \pi : S^n \setminus \{e_{n+1}\} \to \mathbb{R}^n, \qquad \pi(x_1,\dots,x_{n+1}) = \frac{(x_1,\dots,x_n)}{1 - x_{n+1}} $$ be stereographic projection. Extend $\pi$ to $\overline{\mathbb{R}}^n := \mathbb{R}^n \cup \{\infty\}$ by setting $\pi(e_{n+1}) = \infty$, so that $\pi : S^n \to \overline{\mathbb{R}}^n$ is a bijection, and define the chordal metric $q$ on $\overline{\mathbb{R}}^n$ by $$ q(y,z) := \big|\pi^{-1}(y) - \pi^{-1}(z)\big|, $$ the Euclidean distance in $\mathbb{R}^{n+1}$ between the corresponding points of the sphere. Then $\pi : (S^n, |\cdot|) \to (\overline{\mathbb{R}}^n, q)$ is a surjective isometry, and explicitly $$ q(y,z) = \frac{2|y-z|}{\sqrt{1+|y|^2}\sqrt{1+|z|^2}}, \qquad q(y,\infty) = \frac{2}{\sqrt{1+|y|^2}}. $$
